# 🍵 Zenith Chai — The Peak of the Pour

A cinematic, responsive web experience tracing the ancient and modern history of tea through immersive GSAP scroll animations, rich historical imagery, and bilingual English-Urdu design. Built with HTML, CSS, and JavaScript.

---

## ✨ Features

* **Cinematic Scroll Sequence:** Pinned section transitions that cross-fade between historical eras and rich generated imagery seamlessly.
* **Bilingual Typography:** Styled with English serif headlines alongside authentic Urdu script elements.
* **Immersive Chapters:** Journey from ancient China and the Silk Road to royal Mughal courts and bustling modern Lahore street corners.
* **Fully Responsive Design:** Crafted for fluid scaling across desktop and mobile viewports.

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox/Grid, Responsive typography)
* **Interactivity & Animation:** Vanilla JavaScript, GSAP 3, ScrollTrigger Plugin
* **Fonts:** Google Fonts (`Fraunces`, `Inter`, `Noto Nastaliq Urdu`)
